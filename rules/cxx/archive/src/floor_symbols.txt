# What a native static library may leave undefined: the symbols the final link finds in the C library at the glibc floor
# (2.34: libc, libm, libdl and libpthread are one library from that release) and in the compiler runtime the toolchain links.
# One name per line. A name here must exist in glibc 2.34 or earlier: a function added later (strlcpy and arc4random in 2.36 and
# 2.38, pidfd_open in 2.36) is deliberately absent, so a library that calls one is refused while it is built, not when a user links it
# on an older system. A library that needs a symbol not listed names it in the `allow` of its native_archive and says why.
