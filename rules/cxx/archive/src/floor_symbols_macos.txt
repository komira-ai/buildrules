# What a native static library built for macOS may leave undefined: the symbols the final link finds in libSystem (the C library, libm, libpthread, dlfcn and
# the Mach kernel interfaces are one library there) and in the compiler runtime the macOS link brings (compiler-rt builtins for arm64). Names are the C names:
# a Mach-O symbol carries one more leading underscore, which archive_check removes before it looks the name up. One name per line.
# This is the macOS counterpart of floor_symbols.txt, and what is not in it is a name the checks refuse while the library is built: a library that calls a
# function libSystem has and this list lacks names it in the `allow` of its native_archive and says why. Names glibc has and libSystem lacks (the *64 variants,
# epoll, eventfd, memfd_create, accept4, dup3, pipe2, strchrnul, memrchr, __errno_location, the glibc ctype tables) are deliberately absent.
